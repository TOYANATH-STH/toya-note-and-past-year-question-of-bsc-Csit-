Introduction to Information Technology — Notes

Introduction to Information Technology (CSC109) introduces basic IT concepts, computer fundamentals, and information systems.

Key Topics: Computer fundamentals, generations of computers, hardware & software, input/output devices, memory, operating systems, number systems, data communication basics, internet and WWW, information systems, ethical and social issues in IT.

Important Topics

  • Block diagram of computer, CPU, ALU, control unit.
  • Types of software: system software, application software.
  • Number systems: binary, octal, decimal, hexadecimal conversions.
  • Operating system functions: process, memory, file management.
  • Internet, browsers, search engines, email, WWW architecture.

C Programming — Notes

C Programming (CSC110) is the foundation of computer programming for BSc CSIT students.

Key Topics: Structure of C program, data types, operators, control statements, functions, arrays, pointers, strings, structures, unions, file handling, preprocessor directives, dynamic memory allocation.

Chapter-wise Summary

  • Basics: Structure of C program, compilation, printf/scanf, variables, constants.
  • Control: if-else, switch, loops (while, do-while, for), break, continue.
  • Functions: Declaration, definition, call, recursion, scope.
  • Arrays & Pointers: 1D/2D arrays, pointer arithmetic, dynamic allocation.
  • Structures & Files: Structure definition, array of structures, file operations (fopen, fclose, fprintf, fscanf).

Digital Logic — Notes

Digital Logic (CSC111) covers design of digital circuits using logic gates and Boolean algebra.

Key Topics: Number systems and codes, Boolean algebra, logic gates, K-map simplification, combinational circuits, sequential circuits, flip-flops, counters, registers, memory.

Important Concepts

  • Number conversions, BCD, Gray code, Excess-3.
  • Boolean theorems, De Morgan's laws, SOP and POS.
  • Half/full adder, half/full subtractor, MUX, DEMUX, decoder.
  • SR, JK, D, T flip-flops; counters; shift registers.

Mathematics I — Notes

Mathematics I (MTH112) covers limits, differentiation, integration, matrices, and linear algebra.

Key Topics: Limits and continuity, differentiation, integration, applications of derivatives, matrices and determinants, systems of linear equations, eigenvalues and eigenvectors, sequences and series.

Important Formulas

  • d/dx(xn) = nxn-1; product, quotient, chain rules.
  • Integration: power rule, by parts, substitution, definite integrals.
  • Matrix: addition, multiplication, transpose, inverse, adjoint, determinant.
  • Eigenvalue: det(A - λI) = 0.

Physics — Notes

Physics (PHY113) covers mechanics, heat, optics, electricity, and modern physics relevant to computing.

Key Topics: Vectors and motion, laws of motion, work-energy-power, gravitation, rotational motion, heat and thermodynamics, waves, electrostatics, current electricity, magnetism, electromagnetic induction, modern physics.

Important Formulas

  • F = ma; W = Fs cos θ.
  • V = IR; P = VI = I2R = V2/R.
  • 1/v - 1/u = 1/f (lens); 1/v + 1/u = 1/f (mirror).
