Advanced Database — Notes

Advanced Database (CSC461) covers advanced database concepts beyond basic DBMS.

Key Topics: Distributed databases, object-oriented databases, object-relational databases, data warehouses, data mining, XML databases, NoSQL, temporal/spatial databases, transaction management in distributed DB.

Core Topics

  • Distributed DB: architecture, fragmentation, replication.
  • OODB vs ORDB vs RDB.
  • NoSQL: document, key-value, column-family, graph databases.
  • XML: DTD, XQuery, XPath.
  • Concurrency control and recovery in advanced systems.

Internship — Notes

Internship (CSC462) is the practical training component where students work in an IT organization.

Key Topics: Internship objectives, organization profile, work assignment, tools and technologies used, learning outcomes, internship report format, certificate, presentation, evaluation.

Report Structure

  • Organization profile and history.
  • Department and work assignment details.
  • Technologies and tools used during internship.
  • Tasks performed and problems solved.
  • Learning outcomes and suggestions.
  • Certificate and supervisor evaluation.
