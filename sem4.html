Theory of Computation — Notes

Theory of Computation (CSC257) studies abstract machines and computational problems.

Key Topics: Automata theory, finite automata, regular expressions, context-free grammars, pushdown automata, Turing machines, decidability, complexity classes (P, NP).

Core Concepts

  • DFA, NFA, NFA with epsilon transitions.
  • Regular expressions and regular languages.
  • Context-free grammar, Chomsky normal form.
  • Pushdown automata, Turing machine variants.
  • Halting problem, P vs NP.

Computer Networks — Notes

Computer Networks (CSC258) covers network architecture, protocols, and data communication.

Key Topics: OSI and TCP/IP models, network devices, IP addressing, subnetting, routing, TCP/UDP, HTTP, FTP, SMTP, DNS, DHCP, wireless networks, network security basics.

Network Models

  • OSI 7 layers: physical, data link, network, transport, session, presentation, application.
  • TCP/IP 4 layers.
  • IPv4 addressing, subnetting, CIDR.
  • Routing protocols: RIP, OSPF, BGP basics.

Protocols

  • TCP: three-way handshake, flow control, congestion control.
  • UDP: connectionless, applications.
  • HTTP, FTP, SMTP, DNS, DHCP, SNMP.

Operating Systems — Notes

Operating Systems (CSC259) studies OS design: process, memory, file, device management.

Key Topics: OS structure/services, process management, synchronization, CPU scheduling, deadlocks, memory management, virtual memory, file system, disk management, I/O, protection/security, case studies (Windows, Linux).

Scheduling

  • FCFS, SJF, SRTF, priority, round robin.
  • Metrics: turnaround, waiting, response time, throughput.

Memory

  • Paging, segmentation, page replacement (FIFO, LRU, optimal).
  • Thrashing, working set.

Database Management System — Notes

DBMS (CSC260) covers database design, relational model, SQL, normalization, transactions.

Key Topics: DBMS architecture, ER model, relational model, relational algebra, SQL (DDL, DML, DCL, TCL), joins, subqueries, views, indexes, normalization (1NF- BCNF), functional dependencies, transactions, ACID, concurrency, recovery.

SQL

  • DDL: CREATE, ALTER, DROP, TRUNCATE.
  • DML: SELECT, INSERT, UPDATE, DELETE.
  • Joins: inner, left, right, full, self, cross.

Normalization

  • 1NF, 2NF, 3NF, BCNF with examples.

Artificial Intelligence — Notes

Artificial Intelligence (CSC261) introduces intelligent agents, search, knowledge representation, reasoning.

Key Topics: AI introduction, intelligent agents, problem solving, uninformed/informed search, heuristic search, knowledge representation, propositional/predicate logic, reasoning, uncertainty, expert systems, ML basics, neural networks, NLP basics.

Search

  • Uninformed: BFS, DFS, uniform cost, depth-limited, iterative deepening.
  • Informed: greedy best-first, A*, hill climbing, simulated annealing.
  • Game: minimax, alpha-beta pruning.
