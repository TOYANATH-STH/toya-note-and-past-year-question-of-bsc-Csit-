Data Structure and Algorithms — Notes

Data Structure and Algorithms (CSC206) teaches efficient data organization and problem solving.

Key Topics: Complexity analysis (Big O), arrays, linked lists, stacks, queues, trees, BST, AVL, graphs, sorting, searching, hashing, recursion, greedy, divide and conquer, dynamic programming.

Data Structures

  • Array: row/column major order, address calculation.
  • Linked List: singly, doubly, circular operations.
  • Stack: LIFO, push/pop, infix to postfix conversion.
  • Queue: FIFO, circular queue, priority queue.
  • Tree: traversals (in/pre/post), BST, AVL rotations.
  • Graph: BFS, DFS, Prim's, Kruskal's, Dijkstra's.

Numerical Method — Notes

Numerical Method (CSC207) gives computational techniques for mathematical problems.

Key Topics: Errors in computation, nonlinear equations, interpolation, numerical differentiation/integration, linear systems, ODEs, curve fitting, least squares.

Methods

  • Root finding: bisection, regula-falsi, Newton-Raphson, secant.
  • Linear systems: Gauss elimination, Gauss-Jordan, LU, Gauss-Seidel, Jacobi.
  • Interpolation: Newton's divided difference, Lagrange, spline.
  • Integration: trapezoidal, Simpson's rules.
  • ODE: Euler, Runge-Kutta 4th order.

Computer Architecture — Notes

Computer Architecture (CSC208) focuses on computer system structure and behavior.

Key Topics: Computer organization, CPU structure, instruction cycle, control unit, pipelining, memory hierarchy, cache, main/secondary storage, I/O, interrupts, DMA, parallel processing, RISC vs CISC.

Concepts

  • Von Neumann and Harvard architecture.
  • Instruction cycle: fetch, decode, execute, store.
  • Cache: mapping techniques, hit ratio, miss penalty.
  • Virtual memory: paging, segmentation, replacement (FIFO, LRU, OPT).
  • Pipelining hazards: structural, data, control.

Computer Graphics — Notes

Computer Graphics (CSC209) covers image generation, 2D/3D graphics and rendering.

Key Topics: Graphics primitives, line/circle algorithms, polygon filling, 2D/3D transformations, clipping, projections, hidden surface removal, shading, curves, animation.

2D Graphics

  • Line: DDA, Bresenham's algorithm.
  • Circle: midpoint circle algorithm.
  • Transformations: translation, rotation, scaling, reflection, shearing.
  • Clipping: Cohen-Sutherland, Liang-Barsky, Sutherland-Hodgman.

3D Graphics

  • Parallel and perspective projection.
  • Hidden surface: Z-buffer, painter's algorithm.
  • Shading: flat, Gouraud, Phong.
  • Curves: Bezier, B-splines.

Statistics II — Notes

Statistics II (STA210) covers probability theory, distributions, estimation, and inferential statistics.

Key Topics: Probability axioms, conditional probability, Bayes' theorem, random variables, distributions (binomial, Poisson, normal), expectation, variance, sampling, estimation, hypothesis testing, chi-square, t-test, ANOVA.

Distributions

  • Binomial: mean np, variance npq.
  • Poisson: mean = variance = λ.
  • Normal: standard normal, Z-score.
