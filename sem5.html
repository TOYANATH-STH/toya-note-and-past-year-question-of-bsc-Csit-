Design and Analysis of Algorithms — Notes

DAA (CSC314) covers algorithm design techniques and analysis.

Key Topics: Asymptotic analysis, recurrence relations, divide and conquer, greedy method, dynamic programming, backtracking, branch and bound, sorting, graph algorithms, NP-completeness.

Techniques

  • Big O, Omega, Theta notations.
  • Master theorem for recurrences.
  • Merge sort, quick sort, binary search (divide and conquer).
  • Activity selection, Huffman coding, knapsack (greedy).
  • Matrix chain multiplication, LCS, optimal BST (DP).
  • N-queens, sum of subset (backtracking).

System Analysis and Design — Notes

SAD (CSC315) covers analyzing requirements and designing information systems.

Key Topics: System concepts, SDLC, feasibility study, requirement gathering, DFD, data dictionary, ER diagram, decision trees/tables, system design, testing, implementation, maintenance.

SDLC Phases

  • Preliminary investigation, feasibility study.
  • System analysis: DFD levels 0 and 1, data dictionary.
  • System design: logical and physical design.
  • Development, testing, implementation, maintenance.

Cryptography — Notes

Cryptography (CSC316) covers securing information through encryption and decryption.

Key Topics: Classical ciphers, symmetric encryption (DES, AES), asymmetric encryption (RSA, Diffie-Hellman), hash functions, digital signatures, key management, PKI, cryptographic protocols.

Core Concepts

  • Substitution and transposition ciphers.
  • DES, 3DES, AES block ciphers.
  • RSA algorithm, Diffie-Hellman key exchange.
  • Message digest, MD5, SHA family.
  • Digital signature, certificates, PKI.

Simulation and Modeling — Notes

Simulation and Modeling (CSC317) covers creating models of real systems and simulating them.

Key Topics: System concept, model types, discrete/continuous simulation, random number generation, queuing models, inventory models, validation, verification, simulation languages, case studies.

Key Areas

  • System, model, simulation, types of models.
  • Discrete event simulation, continuous simulation.
  • Random numbers: mid-square, congruential methods.
  • Queuing models, inventory models.
  • Verification and validation of simulation models.
