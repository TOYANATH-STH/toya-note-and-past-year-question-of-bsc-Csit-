Advanced Java Programming — Notes

Advanced Java Programming (CSC409) covers advanced Java concepts and enterprise development.

Key Topics: JDBC, Servlets, JSP, JavaBeans, EJB basics, RMI, multithreading, collections framework, GUI (Swing/AWT), exception handling, file I/O, generics, lambda expressions.

Enterprise Java

  • JDBC: connecting to database, executing queries.
  • Servlets: lifecycle, doGet/doPost, session tracking.
  • JSP: directives, actions, implicit objects, JSTL.
  • Swing/AWT: components, event handling, layout managers.

Data Warehousing and Data Mining — Notes

Data Warehousing and Data Mining (CSC410) covers data warehouses and mining techniques.

Key Topics: Data warehouse fundamentals, OLAP vs OLTP, data warehouse architecture, ETL, data mining process, classification, clustering, association rules, data preprocessing, evaluation.

Core Concepts

  • Data warehouse characteristics: subject-oriented, integrated, time-variant, non-volatile.
  • OLTP vs OLAP.
  • Data mining: classification (decision tree, Naive Bayes), clustering (K-means), association (Apriori).
  • Data preprocessing: cleaning, integration, transformation, reduction.

Principles of Management — Notes

Principles of Management (MGT411) covers management theories and practices.

Key Topics: Management introduction, functions of management, planning, organizing, staffing, leading, controlling, motivation, leadership, communication, decision making, organizational behavior.

Functions

  • Planning: types, steps, importance.
  • Organizing: organization structure, delegation, centralization/decentralization.
  • Staffing: recruitment, selection, training.
  • Leading: motivation theories, leadership styles.
  • Controlling: control process, types of control.

Project Work — Notes

Project Work (CSC412) is the final-year project phase where students build a complete software system.

Key Topics: Problem identification, project proposal, literature review, feasibility, requirement analysis, system design, DFD/ER/UML diagrams, implementation, testing, documentation, presentation, viva.

Report Structure

  • Abstract, introduction, literature review.
  • System analysis and design.
  • Implementation, testing, results.
  • Conclusion, future work, references.
