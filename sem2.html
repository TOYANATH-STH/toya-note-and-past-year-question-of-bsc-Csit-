Discrete Structure — Notes

Discrete Structure (CSC160) provides the mathematical foundation for computer science.

Key Topics: Propositional and predicate logic, set theory, relations and functions, mathematical induction, recurrence relations, combinatorics, graph theory, trees, algebraic structures.

Core Topics

  • Logical connectives, truth tables, tautology, contradiction, logical equivalence.
  • Set operations, Venn diagrams, Cartesian product, power set.
  • Relations: reflexive, symmetric, transitive, equivalence, partial order.
  • Functions: injective, surjective, bijective, inverse, composition.
  • Graph theory: vertex, edge, path, cycle, Euler and Hamiltonian paths.

Object Oriented Programming — Notes

Object Oriented Programming (CSC161) teaches OOP using C++.

Key Topics: Classes and objects, encapsulation, inheritance, polymorphism, abstraction, constructors/destructors, function/operator overloading, virtual functions, templates, exception handling, file handling.

OOP Pillars

  • Encapsulation: access specifiers (public, private, protected).
  • Inheritance: single, multiple, multilevel, hierarchical, hybrid.
  • Polymorphism: compile-time (overloading) and run-time (virtual/overriding).
  • Abstraction: abstract classes, pure virtual functions.

Microprocessor — Notes

Microprocessor (CSC162) covers microprocessor architecture, instruction sets, and assembly language.

Key Topics: 8085/8086 architecture, registers, flags, buses, instruction set, addressing modes, assembly language programming, interrupts, memory organization, I/O organization.

Architecture Highlights

  • 8086: 16-bit, BIU and EU, segment registers (CS, DS, SS, ES), IP.
  • Addressing modes: immediate, direct, register, indirect, based indexed.
  • Interrupts: hardware vs software, maskable vs non-maskable.
  • Memory: RAM, ROM, cache, virtual memory.

Mathematics II — Notes

Mathematics II (MTH163) covers vectors, calculus of several variables, differential equations, Laplace and Fourier transforms.

Key Topics: Vectors, partial differentiation, multiple integrals, vector calculus (gradient, divergence, curl), ODEs, Laplace transform, Fourier series, complex numbers.

Formulas

  • Gradient: ∇f = (&partial;f/&partial;x, &partial;f/&partial;y, &partial;f/&partial;z).
  • Linear ODE: dy/dx + P(x)y = Q(x).
  • Laplace: L{f(t)} = ∫0∞ e-st f(t) dt.

Statistics I — Notes

Statistics I (STA164) introduces statistical methods for data analysis.

Key Topics: Data classification, frequency distribution, central tendency, dispersion, skewness, kurtosis, correlation, regression, probability, probability distributions, sampling, hypothesis testing basics.

Formulas

  • Mean: &xbar; = ∑x/n.
  • Variance: σ2 = ∑(x-&xbar;)2/n.
  • Correlation coefficient r.
  • Regression: y = a + bx.
  • Binomial: P(x) = nCx px qn-x.
